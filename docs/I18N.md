# Interface en deux langues (S08, S14)

Sorti du `CLAUDE.md` (règle R03). À lire en modifiant un texte de l'interface, `Help.svelte` ou un guide d'installation.

- Tout texte de la page passe par `t('texte français')` (`ui/src/lib/i18n.svelte.ts` ; `tx('…')` pour une constante) et a sa traduction dans `ui/src/lib/locales/en.ts`.
- Un texte venu de Rust (modes, erreurs, messages de la pastille, catalogue de téléchargements) a la sienne dans `locales/en-server.ts` (un modèle avec `{valeur}` se reconnaît dans le message reçu).
- `i18n.test.ts` échoue si un texte n'est pas traduit, si une traduction est orpheline ou si les `{valeurs}` diffèrent.
- L'Aide anglaise est un fichier à part (`ui/src/tabs/HelpEn.svelte`) : toute modification de `Help.svelte` s'y reporte (le test compare leurs structures).
- Le menu de l'icône se traduit en Rust (`crates/cli/src/tray_source.rs`).
- Le journal, le rapport et la documentation restent en français, **sauf** `README.en.md` et les guides d'installation `docs/INSTALLATION_*.en.md` (S14) : toute modification d'un guide français s'y reporte, et inversement (les libellés de l'interface anglaise sont dans `locales/en.ts`).
